# Contributing

Hey! Thanks for taking an interest in contributing to discord-player-youtubei. We hope you will like it here.

# A little about AI

Though code written with AI is allowed, we do not allow it for first time contributor. It is very easy to detect AI specifically in this project due to YouTube constantly changing their platform. If you are a first time contributor and have used AI, your PR will be closed and a warning will be issued. If you again submit AI code, you will be banned from the repository.

If you are already an existing contributor, usage of AI is allowed. However, you are required to declare this in your pull request as well as in-file using the `region` syntax.

```ts
// #region YourFeature (AI) (gh username)
someFeature()
// #endregion
```

```md
I have used (name of AI model) in this pull request. Below are the files with snippets of AI generated code
- [`file`](https://example.com/linktofile)

I also declare that I have proof-read, understood and tested the code generated by AI. 
```

Failure to do so may result in suspension from the repository. Addationally, if you submit AI generated code, you are expected to understand and test the code the AI has generated. Blindly submitting AI generated code will also result in penalty.

For both existing and new contributors, fully AI generated pull requests are strictly forbidden.

# Steps to contribute

1. Clone the repository
2. Make some changes (do not increment the package's version)
3. Lint. Use the built in script `yarn run format-and-lint:fix`
4. Create a pull request
5. Wait for review from one of our maintainers
